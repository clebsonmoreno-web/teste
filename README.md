# teste

Projeto de edição de vídeos com Remotion, React e TypeScript em `video-editor/`.

```sh
cd video-editor
npm ci
npm run demo
npm run studio
```

Consulte `video-editor/README.md` para importar vídeos, sincronizar ícones e exportar MP4 com todas as faixas de áudio originais copiadas sem recodificação.

Para testar pelo navegador no GitHub Codespaces, use a branch `feat/video-editor`. A configuração em `.devcontainer/` prepara e inicia o editor automaticamente e encaminha a porta 5173. Siga `.devcontainer/COMECE-AQUI.md` e confira sua franquia gratuita antes de criar o ambiente. Nenhum Codespace ou serviço pago é criado pelo repositório.
